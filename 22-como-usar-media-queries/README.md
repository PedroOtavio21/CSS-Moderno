# Aula 22 - Como usar media queries para layouts responsivos
Nesta aula, veremos como utilizar os media queries na prática, para criar layouts responsivos.

## Boas práticas de uso
Sempre que possível, quando trabalhar em páginas onde serão trabalhadas estilizações de responsividade, priorize boas práticas de **mobile first**, ou seja, o código padrão em CSS voltado para dispositivos móveis, com medias queries voltadas para diferentes breakpoints para dispositivos maiors (tablets e desktops).

Outra boa prática é evitar utilizar diversos breakpoints de media queries sem a necessidade, podendo estes ter seus problemas resolvidos, na maioria das vezes, no estilo padrão da página web,

Além disso, documente o código sempre que possível para melhor entendimento de terceiros ou consultas individuais ao decorrer do tempo em que o site teve seu deploy.
